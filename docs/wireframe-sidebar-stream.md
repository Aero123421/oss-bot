# ワイヤー（ラベルのみ）案B｜サイドバー＋ストリーム

比喩：AI版Slack／実装コピー禁止。この1枚は**領域とラベル**だけ。ピクセル・色・アイコンは後続。
BYO／AuthGate／Dispatcher窓口を反映。

## A. AuthGate未設定（空状態・会話の前）

```
┌────────────────────────────────────────────┐
│ ワークスペースに入るにはセットアップが必要です │
│                                            │
│  [ ./doctor を実行 ]   [ ドキュメント ]      │
│                                            │
│ （設定ツリーなし／モデルピッカーなし）         │
└────────────────────────────────────────────┘
```

## B. 通過後ホーム（サイドバー＋ストリーム）

```
┌──────────────┬────────────────────────────────────────────┐
│ WORKSPACE    │ ROOM HEADER / DM HEADER                    │
│ oss-bot      │ #知的生産  または  参謀（窓口）               │
│              │ 在席: 薄い気配のみ（実行中だけ強調）         │
│──────────────┤────────────────────────────────────────────│
│ ルーム       │ STREAM                                     │
│ #知的生産 ●  │                                            │
│ #実装チーム  │  [リサーチ] 結論：…                        │
│              │                                            │
│ DM           │  ┌─ 承認／修復カード ────────────────┐   │
│ ★参謀（窓口）│  │ GitHub 再認証が必要です             │   │
│   ●要判断    │  │ [再認証] [後で]                     │   │
│ 自分用Bot    │  └────────────────────────────────────┘   │
│  Ready       │                                            │
│ リサーチ     │  ┌─ doctor失敗カード ────────────────┐   │
│  未ログイン  │  │ Docker が赤：直す → docker …        │   │
│──────────────│  │ [doctorを開く]                      │   │
│ 要対応 (2)   │  └────────────────────────────────────┘   │
│ ◆ 承認 GitHub│                                            │
│ ● @あなた    │────────────────────────────────────────────│
│ （設定なし） │ メッセージ入力 …  @でBot呼出               │
└──────────────┴────────────────────────────────────────────┘
```

★ = Dispatcher窓口（上位固定）。Bot行に Ready／未ログイン。

## ラベル凡例

| 領域 | 置くもの | 置かないもの |
|------|----------|--------------|
| AuthGate空状態 | doctor／Setup CTA | 空のチャットホーム、設定ツリー |
| サイドバーDM | Dispatcher窓口固定、Bot＋状態 | モデル一覧、Integrations |
| 未読 | ●通常 ＜ ◆要判断（承認・再認証・doctor赤） | 全ログ赤点灯 |
| ヘッダ | 薄い在席（実行中のみ） | 全員オンライン同期 |
| ストリーム | 発言、インライン承認／修復 | 生ログ、秘密の生値 |
| 第2層 | コネクタ・ルーチン・設定 | 常時マルチパネル |

## 受け入れ（このワイヤー準拠）

- [ ] AuthGate未設定は専用空状態
- [ ] 参謀（Dispatcher）がDM上位固定
- [ ] Botに Ready／未ログインが見える
- [ ] 承認・再認証・doctor失敗がストリーム内カード
- [ ] サイドバーに設定項目がない
- [ ] 秘密の生値が出ない
