# ワイヤー（ラベルのみ）案B｜サイドバー＋ストリーム

比喩：AI版Slack／実装コピー禁止。この1枚は**領域とラベル**だけ。ピクセル・色・アイコンは後続。

```
┌──────────────┬────────────────────────────────────────────┐
│ WORKSPACE    │ ROOM HEADER                                │
│ oss-bot      │ #知的生産                                  │
│              │ 在席: 参謀 · リサーチ(実行中) · デザイン … │
│──────────────┤────────────────────────────────────────────│
│ ルーム       │ STREAM                                     │
│ #知的生産 ●  │                                            │
│ #実装チーム  │  [リサーチ] 結論：…                        │
│ #幹部会議    │                                            │
│              │  ┌─ スレッド・チップ ─────────────────┐   │
│ DM           │  │ 詳細比較表（開く）                  │   │
│ 参謀 ●要判断 │  └────────────────────────────────────┘   │
│ 自分用Bot    │                                            │
│ リサーチ     │  ┌─ 承認カード ──────────────────────┐   │
│              │  │ GitHub を接続しますか？             │   │
│──────────────│  │ [許可]  [拒否]  [後で]              │   │
│ 要対応 (2)   │  └────────────────────────────────────┘   │
│ · 承認 GitHub│                                            │
│ · @あなた    │  [デザイン] ワイヤー案を出した             │
│              │                                            │
│              │────────────────────────────────────────────│
│ （設定なし） │ メッセージ入力 …  @でBot呼出               │
└──────────────┴────────────────────────────────────────────┘
```

## ラベル凡例

| 領域 | 置くもの | 置かないもの |
|------|----------|--------------|
| サイドバー上 | ルーム一覧、DM一覧 | 設定ツリー、モデル一覧、Integrations |
| 未読 | `●` 通常新着／`要判断` 承認・@優先 | 全ログの赤点灯 |
| ルームヘッダ | ルーム名、在席、実行中 | Adminリンク、モデルピッカー |
| ストリーム | 発言、在席に紐づく誰の声か、インライン承認 | 生ログ、RAGホーム、設定パネル |
| スレッド | 長文・差分の脇 | 本流への全文ダンプ |
| 要対応 | 承認／@／ルーチン結果のトリアージ | 「すべての新着」のダンプ |
| 第2層 | コネクタ・ルーチン・設定（ヘッダ…またはカードから） | 常時マルチパネル |

## 初回着地（参考）

`./up` 成功後の最初の画面はダッシュボードではなく **自分用BotのDM**：短い挨拶＋次の一手（ルーム作成／並列投下）。承認カードはストリームに刺さる。

## 受け入れ（このワイヤー準拠）

- [ ] サイドバーに設定項目がない
- [ ] ヘッダに在席／実行中がある
- [ ] 承認がストリーム内カードである
- [ ] BotがDMメンバーとして並ぶ（名簿ドロップダウンではない）
